# 阶段 9~12：商品管理（品牌 / 分类 / 平台属性 / SPU / SKU）

> 本指南实现 `src/views/product/` 下的商品管理模块。后端契约已敲定，前端按既有栈落地。接口调用统一使用 `openapi-fetch` 客户端（详见 `src/api/client.ts`），类型来自自动生成的 `src/api/schema.d.ts`。

### 0.1 后端接口契约（实现时照搬）

> 全部前缀 `/api/v1/product`。路径参数均为 **string**（如 `{skuId}`、`{category3Id}`、`{trademarkId}`），调用时务必传字符串。
> 分页统一参数 `page` / `limit`，响应 `data.records` + `data.total`。

| 业务 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 品牌分页 | GET | `/api/v1/product/trademark?page&limit` | 返回 `ResponseTmList` |
| 品牌全量（下拉用） | GET | `/api/v1/product/trademark/all` | 返回 `Trademark[]`，不分页 |
| 新增品牌 | POST | `/api/v1/product/trademark` | body `ParamTmSave` |
| 更新品牌 | PUT | `/api/v1/product/trademark/{trademarkId}` | body `ParamTmUpdate` |
| 删除品牌 | DELETE | `/api/v1/product/trademark/{trademarkId}` | |
| 一级分类 | GET | `/api/v1/product/category1` | 不分页 |
| 二级分类 | GET | `/api/v1/product/category2/{category1Id}` | 路径参数 |
| 三级分类 | GET | `/api/v1/product/category3/{category2Id}` | 路径参数 |
| 新增一级 | POST | `/api/v1/product/category1` | body `ParamCategory1` |
| 新增二级 | POST | `/api/v1/product/category2/{category1Id}` | body `ParamCategory2` |
| 新增三级 | POST | `/api/v1/product/category3/{category2Id}` | body `ParamCategory3` |
| 平台属性列表 | GET | `/api/v1/product/attrinfo/{category1Id}/{category2Id}/{category3Id}` | 三级路径参数 |
| 新增/修改属性 | POST | `/api/v1/product/attrinfo` | body `AttrInfo`（`attrId` 存在即改） |
| 删除属性 | DELETE | `/api/v1/product/attrinfo/{attrId}` | |
| SPU 分页 | GET | `/api/v1/product/spuinfo?page&limit&category3Id` | 必须带 `category3Id` |
| SPU 新增 | POST | `/api/v1/product/spuinfo` | body `Spu`（含图片/销售属性） |
| SPU 修改 | PUT | `/api/v1/product/spuinfo` | body `Spu` |
| SPU 删除 | DELETE | `/api/v1/product/spuinfo/{spuId}` | |
| SPU 图片列表 | GET | `/api/v1/product/spuImage/{spuId}` | |
| SPU 销售属性 | GET | `/api/v1/product/spuSaleAttr/{spuId}` | |
| 基础销售属性 | GET | `/api/v1/product/baseSaleAttr` | |
| SKU 分页 | GET | `/api/v1/product/sku?page&limit` | |
| SKU 新增 | POST | `/api/v1/product/sku` | body `SkuInfo` |
| SKU 详情 | GET | `/api/v1/product/sku/{skuId}` | |
| SKU 删除 | DELETE | `/api/v1/product/sku/{skuId}` | |
| 上架 | PUT | `/api/v1/product/sku/{skuId}/onsale` | |
| 下架 | PUT | `/api/v1/product/sku/{skuId}/cancelsale` | |
| 文件上传 | POST | `/api/v1/upload` | body `multipart/form-data`，`data` 为 URL 字符串 |

> 类型均以 `components['schemas']['types.XXX']` 从 `schema.d.ts` 推导，例如 `type Trademark = components['schemas']['types.Trademark']`。

### 0.2 前端调用约定（务必遵守）

#### 0.2.1 客户端 `client` 与错误处理

```ts
// src/api/client.ts 已封装 openapi-fetch 实例，并挂载了响应中间件：
//   - HTTP 非 2xx 或响应体 code !== 200 → ElMessage.error + throw
//   - 成功时返回 { data }，业务取 data?.data
// 页面一律 try/catch，不写 code===200 判断；catch 空处理即可（中间件已提示）。

import { client } from '@/api/client'

const { data } = await client.GET('/api/v1/product/trademark', {
  params: { query: { page: 1, limit: 5 } },
})
const list = data?.data.records ?? []
const total = data?.data.total ?? 0
```

写操作（新增/修改/删除）直接 `await`，不赋值：

```ts
await client.POST('/api/v1/product/trademark', { body: { tmName, logoUrl } })
await client.PUT('/api/v1/product/trademark/{trademarkId}', {
  params: { path: { trademarkId: String(row.tmId) } },
  body: { tmId: String(row.tmId), tmName, logoUrl },
})
await client.DELETE('/api/v1/product/trademark/{trademarkId}', {
  params: { path: { trademarkId: String(row.tmId) } },
})
```

> 路径参数用 `params.path`，且 `trademarkId` / `skuId` 等都是 **string**，记得 `String()` 转换。

#### 0.2.2 `el-upload` 鉴权头

`el-upload` 自带的上传请求**不经过 `client` 中间件**，不会自动带 token。本项目后端统一要求 `Authorization: Bearer <token>`（见 `apps/server` 的 auth 中间件、`main.go` swagger 安全头），因此 `el-upload` 必须手动设置该请求头，否则上传会返回 401。开发态 `:action` 走 vite 代理（`/api` 不重写，见 `vite.config.ts`），不要写死绝对地址。token 取自 `localStorage.getItem('token')`（与 `client.ts` 中间件一致）。

```vue
<el-upload
  :action="`/api/v1/upload`"
  :headers="{ Authorization: `Bearer ${localStorage.getItem('token')}` }"
  :on-success="handleImgSuccess"
  :before-upload="beforeUpload"
>
```

#### 0.2.3 UI 约定（图标 / ElMessage 自动导入）

- **图标**：项目用 `unplugin-icons` 自动导入，集合前缀 `ep`/`mdi`，组件名 `<IconEpPlus />`、`<IconEpEdit />`、`<IconEpDelete />`。**无需 import**，直接写标签。
- **ElMessage / ElMessageBox**：`element-plus` 已配自动导入，页面里直接用，无需 import（独立页面若报样式缺失，加 `import 'element-plus/es/components/message/style/css'`）。
- **类型**：从 `schema.d.ts` 取 `components['schemas']['types.XXX']`，不要手写 `type.ts`。

#### 0.2.4 复用 `useCrudTable`（列表类页面专用）

`trademark` / `spu` / `sku` 三个列表分页页可直接复用 `composables/useCrudTable.ts`，已封装：`list`/`total`/`pageNo`/`pageSize`/`keyword`/`loading`、`dialogVisible`/`title`/`form`、`fetchList`/`search`/`reset`/`openAdd`/`openEdit`/`save`/`remove`。

```ts
import { useCrudTable } from '@/composables/useCrudTable'
import type { components } from '@/api/schema'

type Trademark = components['schemas']['types.Trademark']

const { list, total, pageNo, pageSize, loading, dialogVisible, title, form,
        fetchList, search, reset, openAdd, openEdit, save, remove } =
  useCrudTable<Trademark>(
    (page, limit) =>
      client.GET('/api/v1/product/trademark', { params: { query: { page, limit } } }),
    (payload) =>
      payload.tmId
        ? client.PUT('/api/v1/product/trademark/{trademarkId}', {
            params: { path: { trademarkId: String(payload.tmId) } },
            body: { tmId: String(payload.tmId), tmName: payload.tmName!, logoUrl: payload.logoUrl! },
          })
        : client.POST('/api/v1/product/trademark', {
            body: { tmName: payload.tmName!, logoUrl: payload.logoUrl! },
          }),
    (row) =>
      client.DELETE('/api/v1/product/trademark/{trademarkId}', {
        params: { path: { trademarkId: String(row.tmId) } },
      }),
  )
```

> ⚠️ 主键提醒（见 `useCrudTable` 注释）：本栈实体主键命名各异且为 **string**（品牌 `trademarkId`、SPU `spuId`、SKU `skuId`），**不假设 `id`**。新增/编辑判断用对应主键是否存在；删除时 `row.xxxId` 取真实主键。

## 阶段 9：品牌管理 `views/product/trademark/index.vue`

列表 + 新增/编辑弹窗 + 删除，直接套 `useCrudTable`。`logoUrl` 走 `el-upload`（鉴权头见 0.2.2），成功回调把返回的 URL 字符串写回 `form.logoUrl`。

```vue
<script setup lang="ts">
import { client } from '@/api/client'
import { useCrudTable } from '@/composables/useCrudTable'
import type { components } from '@/api/schema'

type Trademark = components['schemas']['types.Trademark']

const {
  list, total, pageNo, pageSize, loading, dialogVisible, title, form,
  fetchList, openAdd, openEdit, save, remove,
} = useCrudTable<Trademark>(
  (page, limit) =>
    client.GET('/api/v1/product/trademark', { params: { query: { page, limit } } }),
  (payload) =>
    payload.tmId
      ? client.PUT('/api/v1/product/trademark/{trademarkId}', {
          params: { path: { trademarkId: String(payload.tmId) } },
          body: { tmId: String(payload.tmId), tmName: payload.tmName!, logoUrl: payload.logoUrl! },

      : client.POST('/api/v1/product/trademark', {
          body: { tmName: payload.tmName!, logoUrl: payload.logoUrl! },
        }),
  (row) =>
    client.DELETE('/api/v1/product/trademark/{trademarkId}', {
      params: { path: { trademarkId: String(row.tmId) } },

function handleLogoSuccess(res: { data?: string }) {
  if (res.data) form.logoUrl = res.data

    return false
  }
  if (raw.size / 1024 > 800) {
    ElMessage.error('图片大小不能超过 800KB')
    return false
  }
  return true
}
</script>

      添加品牌

      <el-table-column label="操作" width="200">
        <template #default="{ row }">
          <el-button size="small" :icon="IconEpEdit" @click="openEdit(row)" />
          <el-popconfirm title="确认删除该品牌？" @confirm="remove(row)">
            <template #reference>
              <el-button size="small" type="danger" :icon="IconEpDelete" />
            </template>
          </el-popconfirm>
        </template>
      </el-table-column>
    </el-table>

    <el-pagination
      v-model:current-page="pageNo"
      v-model:page-size="pageSize"
      :total="total"
      :page-sizes="[5, 10, 20]"
      layout="prev, pager, next, jumper, ->, sizes, total"
```

## 阶段 10：分类管理 `views/product/category/index.vue`

三级联动：选一级拉二级、选二级拉三级。支持新增子级（一级/二级/三级）。分类接口不分页，直接取数组。

```vue
<script setup lang="ts">
import { onMounted, ref } from 'vue'
import { client } from '@/api/client'
import type { components } from '@/api/schema'

type Category1 = components['schemas']['types.Category1']
type Category2 = components['schemas']['types.Category2']
type Category3 = components['schemas']['types.Category3']

const c1List = ref<Category1[]>([])
const c2List = ref<Category2[]>([])
const c3List = ref<Category3[]>([])
const c1Id = ref('')
const c2Id = ref('')
const c3Id = ref('')
const dialogVisible = ref(false)
const newName = ref('')
const addLevel = ref<1 | 2 | 3>(1)

async function loadC1() {
  c1List.value = (await client.GET('/api/v1/product/category1')).data?.data ?? []
}
async function onC1(id: string) {
  c1Id.value = String(id)
  c2List.value = (await client.GET('/api/v1/product/category2/{category1Id}', {
    params: { path: { category1Id: String(id) } },
  })).data?.data ?? []
  c3List.value = []
  c2Id.value = ''
  c3Id.value = ''
}
async function onC2(id: string) {
  c2Id.value = String(id)
  c3List.value = (await client.GET('/api/v1/product/category3/{category2Id}', {
    params: { path: { category2Id: String(id) } },
  })).data?.data ?? []
  c3Id.value = ''
}
async function openAdd(level: 1 | 2 | 3) {
  addLevel.value = level
  newName.value = ''
  dialogVisible.value = true
}
async function saveAdd() {
  try {
    if (addLevel.value === 1) {
      await client.POST('/api/v1/product/category1', { body: { name: newName.value } })
    } else if (addLevel.value === 2) {
      await client.POST('/api/v1/product/category2/{category1Id}', {
        params: { path: { category1Id: c1Id.value } },
        body: { name: newName.value },
      })
    } else {
      await client.POST('/api/v1/product/category3/{category2Id}', {
        params: { path: { category2Id: c2Id.value } },
        body: { name: newName.value },
      })
    }
    ElMessage.success('新增成功')
    dialogVisible.value = false
    if (addLevel.value === 1) await loadC1()
    else if (addLevel.value === 2) await onC1(c1Id.value)
    else await onC2(c2Id.value)
  } catch { /* 中间件已提示 */ }
}

onMounted(loadC1)
</script>

<template>
  <div>
    <el-button type="primary" :icon="IconEpPlus" @click="openAdd(1)">添加一级分类</el-button>

    <el-card style="margin-top: 16px">
      <el-tag
        v-for="c1 in c1List" :key="c1.category1Id"
        @click="onC1(c1.category1Id!)" style="margin: 4px; cursor: pointer"
        :type="c1Id === c1.category1Id ? 'primary' : 'info'"
      >{{ c1.name }} <IconEpPlus @click.stop="openAdd(2)" /></el-tag>
    </el-card>

    <el-card v-if="c2List.length" style="margin-top: 16px">
      <el-tag
        v-for="c2 in c2List" :key="c2.category2Id"
        @click="onC2(c2.category2Id!)" style="margin: 4px; cursor: pointer"
        :type="c2Id === c2.category2Id ? 'primary' : 'info'"
      >{{ c2.name }} <IconEpPlus @click.stop="openAdd(3)" /></el-tag>
    </el-card>

    <el-card v-if="c3List.length" style="margin-top: 16px">
      <el-tag v-for="c3 in c3List" :key="c3.category3Id" style="margin: 4px">{{ c3.name }}</el-tag>
    </el-card>

    <el-dialog v-model="dialogVisible" :title="`添加${addLevel}级分类`">
      <el-form label-width="80px">
        <el-form-item label="名称" required>
          <el-input v-model="newName" placeholder="请输入分类名称" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" @click="saveAdd">确定</el-button>
      </template>
    </el-dialog>
  </div>
</template>
```

## 阶段 11：平台属性 + SPU 管理

### 11.1 平台属性 `views/product/attr/index.vue`

依赖三级分类（见阶段 10 的级联），选定三级后才加载属性列表。属性值内联编辑（标签 + 输入态），提交时整组带上去。

```vue
<script setup lang="ts">
import { onMounted, reactive, ref } from 'vue'
import { client } from '@/api/client'
import type { components } from '@/api/schema'

type AttrInfo = components['schemas']['types.Attr']
type AttrValue = components['schemas']['types.AttrValue']

const c1Id = ref('')
const c2Id = ref('')
const c3Id = ref('')
const list = ref<AttrInfo[]>([])
const dialogVisible = ref(false)
const form = reactive<Partial<AttrInfo>>({ attrName: '', attrValueList: [] })
const inputVal = ref('')

async function loadAttr() {
  if (!c1Id.value || !c2Id.value || !c3Id.value) {
    list.value = []
    return
  }
  list.value = (await client.GET(
    '/api/v1/product/attrinfo/{category1Id}/{category2Id}/{category3Id}',
    { params: { path: {
        category1Id: c1Id.value, category2Id: c2Id.value, category3Id: c3Id.value,
    } } },
  )).data?.data ?? []
}
function openAdd() {
  Object.assign(form, { attrName: '', attrValueList: [], categoryId: c3Id.value })
  dialogVisible.value = true
}
function openEdit(row: AttrInfo) {
  Object.assign(form, { ...row, attrValueList: [...(row.attrValueList ?? [])] })
  dialogVisible.value = true
}
function addValue() {
  const v = inputVal.value.trim()
  if (v && !form.attrValueList!.some((x) => x.valueName === v)) {
    form.attrValueList!.push({ valueName: v })
  }
  inputVal.value = ''
}
function removeValue(i: number) {
  form.attrValueList!.splice(i, 1)
}
async function save() {
  try {
    await client.POST('/api/v1/product/attrinfo', {
      body: {
        attrId: form.attrId,
        attrName: form.attrName!,
        categoryId: form.categoryId!,
        attrValueList: form.attrValueList,
      },
    })
    ElMessage.success('保存成功')
    dialogVisible.value = false
    await loadAttr()
  } catch { /* 中间件已提示 */ }
}
async function remove(row: AttrInfo) {
  try {
    await client.DELETE('/api/v1/product/attrinfo/{attrId}', {
      params: { path: { attrId: String(row.attrId) } },
    })
    ElMessage.success('删除成功')
    await loadAttr()
  } catch { /* 中间件已提示 */ }
}

// 三级联动回调：阶段 10 同款，这里仅触发 loadAttr
async function onC3(id: string) {
  c3Id.value = String(id)
  await loadAttr()
}

onMounted(loadAttr)
</script>

<template>
  <div>
    <!-- 三级分类联动选择（复用阶段 10 的级联组件或简版下拉） -->
    <el-alert v-if="!c3Id" title="请先选择三级分类" type="info" :closable="false" style="margin-bottom: 16px" />

    <el-button type="primary" :icon="IconEpPlus" :disabled="!c3Id" @click="openAdd">添加属性</el-button>

    <el-table :data="list" border style="margin-top: 16px">
      <el-table-column type="index" label="序号" width="70" align="center" />
      <el-table-column prop="attrName" label="属性名称" />
      <el-table-column label="属性值">
        <template #default="{ row }">
          <el-tag v-for="v in row.attrValueList" :key="v.attrValueId" style="margin: 2px">{{ v.valueName }}</el-tag>
        </template>
      </el-table-column>
      <el-table-column label="操作" width="160">
        <template #default="{ row }">
          <el-button size="small" :icon="IconEpEdit" @click="openEdit(row)" />
          <el-button size="small" type="danger" :icon="IconEpDelete" @click="remove(row)" />
        </template>
      </el-table-column>
    </el-table>

    <el-dialog v-model="dialogVisible" title="平台属性">
      <el-form :model="form" label-width="90px">
        <el-form-item label="属性名" required>
          <el-input v-model="form.attrName" />
        </el-form-item>
        <el-form-item label="属性值">
          <el-button :icon="IconEpPlus" @click="addValue">添加属性值</el-button>
          <el-tag
            v-for="(v, i) in form.attrValueList" :key="i"
            closable @close="removeValue(i)" style="margin: 4px"
          >{{ v.valueName }}</el-tag>
        </el-form-item>
        <el-form-item>
          <el-input v-model="inputVal" placeholder="输入属性值后点添加" @keyup.enter="addValue" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" @click="save">确定</el-button>
      </template>
    </el-dialog>
  </div>
</template>
```

```vue
  try {

    else await client.POST('/api/v1/product/spuinfo', { body: spuForm as Spu })

async function openAddSku(row: Spu) {
  Object.assign(skuForm, {
    spuId: row.spuId, tmId: row.tmId, category3Id: row.category3Id,
    skuImageList: [], skuAttrValueList: [], skuSaleAttrValueList: [],

    params: { path: { spuId: String(row.spuId) } },
  })).data?.data ?? []
  attrList.value = (await client.GET(
    '/api/v1/product/attrinfo/{category1Id}/{category2Id}/{category3Id}',

  )).data?.data ?? []

}
async function saveSku() {
  try {
    // 后端按分/毫克存储：UI 输入元/克，提交前换算
    skuForm.priceCent = Math.round(Number(skuForm.priceCent) * 100)
    skuForm.weightMg = Math.round(Number(skuForm.weightMg) * 1000)
    await client.POST('/api/v1/product/sku', { body: skuForm as SkuInfo })
    ElMessage.success('保存成功')
    scene.value = 0
    fetchList()
  } catch { /* 中间件已提示 */ }
}
const defaultSkuImg = ref('')

function handleSpuImg(res: { data?: string }) {
  if (res.data) spuImgList.value.push({ imgUrl: res.data, imgName: '' })
}
function handleSkuImg(res: { data?: string }) {
  if (res.data) {
    skuForm.skuImageList!.push({ imgUrl: res.data, imgName: '' } as SkuImgDTO)
    if (!defaultSkuImg.value) defaultSkuImg.value = res.data
  }
}
function setDefaultImg(img: SkuImgDTO) {
  defaultSkuImg.value = img.imgUrl
}
```

## 阶段 12：SKU 管理 `views/product/sku/index.vue`

列表（套 `useCrudTable`）+ 上架/下架 + 详情抽屉。SKU 新增在阶段 11.2 的 SPU 表单完成。

```vue
<script setup lang="ts">
import { client } from '@/api/client'
import { useCrudTable } from '@/composables/useCrudTable'
import type { components } from '@/api/schema'

type SkuInfo = components['schemas']['types.SkuInfo']
type SkuImgDTO = components['schemas']['types.SkuImgDTO']

function getDefaultImgUrl(list?: SkuImgDTO[]) {
  return list?.[0]?.imgUrl ?? ''

const {
  list, total, pageNo, pageSize, loading, fetchList,
} = useCrudTable<SkuInfo>(

  () => Promise.resolve(),
  (row) =>
    client.DELETE('/api/v1/product/sku/{skuId}', {
      params: { path: { skuId: String(row.skuId) } },

)

const drawer = ref(false)
```

## 统一检查清单（实现后核对）

- [ ] 所有接口走 `client.GET/POST/PUT/DELETE`，无 axios / request.ts / code===200 判断
- [ ] 路径参数用 `params.path`，且为**字符串**（`String(id)`）
- [ ] `el-upload` 的 `:action` 为 `/api/v1/upload`、`:headers` 带 `Authorization: Bearer` + `localStorage` token
- [ ] 主键用真实字段（`trademarkId`/`spuId`/`skuId`），不写 `row.id`

- [ ] 列表页复用 `useCrudTable`，不重写分页样板
- [ ] 类型全部来自 `schema.d.ts`，无手写 `type.ts`
- [ ] 价格/重量按 `priceCent`/`weightMg`（分/毫克）换算提交
