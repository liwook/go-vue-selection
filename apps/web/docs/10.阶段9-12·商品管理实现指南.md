# 阶段 9~12：商品管理（品牌 / 分类 / 平台属性 / SPU / SKU）

> 本指南实现 `src/views/product/` 下的商品管理模块。后端契约已敲定，前端按既有栈落地。接口调用统一使用 `openapi-fetch` 客户端（详见 `src/api/client.ts`），类型来自自动生成的 `src/api/schema.d.ts`。

### 0.1 后端接口契约（实现时照搬）

> 全部前缀 `/api/v1/product`。路径参数均为 **string**（如 `{skuId}`、`{category3Id}`、`{trademarkId}`），调用时务必传字符串。
> 分页统一参数 `page` / `limit`，响应 `data.records` + `data.total`。

| 业务 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 品牌分页 | GET | `/api/v1/product/trademark?page&limit` | 返回 `ResponseTmList` |
| 品牌全量（下拉用） | GET | `/api/v1/product/trademark/all` | 返回 `Trademark[]`，不分页 |
| 新增品牌 | POST | `/api/v1/product/trademark` | body `ParamTmSave` |
| 更新品牌 | PUT | `/api/v1/product/trademark/{trademarkId}` | body `ParamTmUpdate` |
| 删除品牌 | DELETE | `/api/v1/product/trademark/{trademarkId}` | |
| 一级分类 | GET | `/api/v1/product/category1` | 不分页 |
| 二级分类 | GET | `/api/v1/product/category2/{category1Id}` | 路径参数 |
| 三级分类 | GET | `/api/v1/product/category3/{category2Id}` | 路径参数 |
| 新增一级 | POST | `/api/v1/product/category1` | body `ParamCategory1` |
| 新增二级 | POST | `/api/v1/product/category2/{category1Id}` | body `ParamCategory2` |
| 新增三级 | POST | `/api/v1/product/category3/{category2Id}` | body `ParamCategory3` |
| 平台属性列表 | GET | `/api/v1/product/attr/{category1Id}/{category2Id}/{category3Id}` | 三级路径参数 |
| 新增/修改属性 | POST | `/api/v1/product/attr` | body `Attr`（`attrId` 存在即改） |
| 删除属性 | DELETE | `/api/v1/product/attr/{attrId}` | |
| SPU 分页 | GET | `/api/v1/product/spu?page&limit&category3Id` | 必须带 `category3Id`（number） |
| SPU 新增 | POST | `/api/v1/product/spu` | body `Spu`（含图片/销售属性） |
| SPU 修改 | PUT | `/api/v1/product/spu/{spuId}` | body `Spu` |
| SPU 图片列表 | GET | `/api/v1/product/spu/{spuId}/images` | 返回 `SpuImage[]` |
| 基础销售属性 | GET | `/api/v1/product/baseSaleAttr` | 返回 `SaleAttr[]` |
| SKU 分页 | GET | `/api/v1/product/sku?page&limit` | |
| SKU 新增 | POST | `/api/v1/product/sku` | body `SkuInfo` |
| SKU 详情 | GET | `/api/v1/product/sku/{skuId}` | 返回 `ResponseSkuInfo` |
| SKU 删除 | DELETE | `/api/v1/product/sku/{skuId}` | |
| 上架 | PUT | `/api/v1/product/sku/{skuId}/onsale` | |
| 下架 | PUT | `/api/v1/product/sku/{skuId}/cancelsale` | |
| 文件上传 | POST | `/api/v1/product/fileUpload` | body `multipart/form-data`，`data` 为 URL 字符串 |

> 类型均以 `components['schemas']['types.XXX']` 从 `schema.d.ts` 推导，例如 `type Trademark = components['schemas']['types.Trademark']`。

### 0.2 前端调用约定（务必遵守）

#### 0.2.1 客户端 `client` 与错误处理

```ts
// src/api/client.ts 已封装 openapi-fetch 实例，并挂载了响应中间件：
//   - HTTP 非 2xx 或响应体 code !== 200 → ElMessage.error + throw
//   - 成功时返回 { data }，业务取 data?.data
// 页面一律 try/catch，不写 code===200 判断；catch 空处理即可（中间件已提示）。

import { client } from '@/api/client'

const { data } = await client.GET('/api/v1/product/trademark', {
  params: { query: { page: 1, limit: 5 } },
})
const list = data?.data.records ?? []
const total = data?.data.total ?? 0
```

写操作（新增/修改/删除）直接 `await`，不赋值：

```ts
await client.POST('/api/v1/product/trademark', { body: { tmName, logoUrl } })
await client.PUT('/api/v1/product/trademark/{trademarkId}', {
  params: { path: { trademarkId: String(row.tmId) } },
  body: { tmId: String(row.tmId), tmName, logoUrl },
})
await client.DELETE('/api/v1/product/trademark/{trademarkId}', {
  params: { path: { trademarkId: String(row.tmId) } },
})
```

> 路径参数用 `params.path`，且 `trademarkId` / `skuId` 等都是 **string**，记得 `String()` 转换。

#### 0.2.2 `el-upload` 鉴权头

`el-upload` 自带的上传请求**不经过 `client` 中间件**，不会自动带 token。本项目后端统一要求 `Authorization: Bearer <token>`（见 `apps/server` 的 auth 中间件、`main.go` swagger 安全头），因此 `el-upload` 必须手动设置该请求头，否则上传会返回 401。开发态 `:action` 走 vite 代理（`/api` 不重写，见 `vite.config.ts`），不要写死绝对地址。token 取自 `localStorage.getItem('token')`（与 `client.ts` 中间件一致）。

```vue
<el-upload
  :action="`/api/v1/product/fileUpload`"
  :headers="{ Authorization: `Bearer ${localStorage.getItem('token')}` }"
  :on-success="handleImgSuccess"
  :before-upload="beforeUpload"
>
```

#### 0.2.3 UI 约定（图标 / ElMessage 自动导入）

- **图标**：商品管理使用 `@element-plus/icons-vue`，在 `<script setup>` 中按需 import 后在模板用 `:icon` 绑定，例如 `<el-button :icon="Plus" />`、`<el-button :icon="Delete" />`、`<el-button :icon="View" />`。常用：`Plus`、`Edit`、`Delete`、`View`、`Search`。
- **ElMessage / ElMessageBox**：`element-plus` 已配自动导入，页面里直接用，无需 import（独立页面若报样式缺失，加 `import 'element-plus/es/components/message/style/css'`）。
- **类型**：从 `schema.d.ts` 取 `components['schemas']['types.XXX']`，不要手写 `type.ts`。

#### 0.2.4 复用 `useCrudTable`（列表类页面专用）

`trademark` / `spu` / `sku` 三个列表分页页可直接复用 `composables/useCrudTable.ts`，已封装：`list`/`total`/`pageNo`/`pageSize`/`keyword`/`loading`、`dialogVisible`/`title`/`form`、`fetchList`/`search`/`reset`/`openAdd`/`openEdit`/`save`/`remove`。

```ts
import { useCrudTable } from '@/composables/useCrudTable'
import type { components } from '@/api/schema'

type Trademark = components['schemas']['types.Trademark']

const { list, total, pageNo, pageSize, loading, dialogVisible, title, form,
        fetchList, search, reset, openAdd, openEdit, save, remove } =
  useCrudTable<Trademark>(
    (page, limit) =>
      client.GET('/api/v1/product/trademark', { params: { query: { page, limit } } }),
    (payload) =>
      payload.tmId
        ? client.PUT('/api/v1/product/trademark/{trademarkId}', {
            params: { path: { trademarkId: String(payload.tmId) } },
            body: { tmId: String(payload.tmId), tmName: payload.tmName!, logoUrl: payload.logoUrl! },
          })
        : client.POST('/api/v1/product/trademark', {
            body: { tmName: payload.tmName!, logoUrl: payload.logoUrl! },
          }),
    (row) =>
      client.DELETE('/api/v1/product/trademark/{trademarkId}', {
        params: { path: { trademarkId: String(row.tmId) } },
      }),
  )
```

> ⚠️ 主键提醒（见 `useCrudTable` 注释）：本栈实体主键命名各异且为 **string**（品牌 `trademarkId`、SPU `spuId`、SKU `skuId`），**不假设 `id`**。新增/编辑判断用对应主键是否存在；删除时 `row.xxxId` 取真实主键。

```vue
<script setup lang="ts">
import { Plus } from '@element-plus/icons-vue'
import { client } from '@/api/client'
import { useCrudTable } from '@/composables/useCrudTable'
import type { components } from '@/api/schema'

type Trademark = components['schemas']['types.Trademark']

const {
  list, total, pageNo, pageSize, loading, dialogVisible, title, form,
  fetchList, openAdd, openEdit, save, remove,
} = useCrudTable<Trademark>(
  (page, limit) =>
    client.GET('/api/v1/product/trademark', { params: { query: { page, limit } } }),

    payload.tmId
      ? client.PUT('/api/v1/product/trademark/{trademarkId}', {
```

## 阶段 10：分类管理 `views/product/category/index.vue`

三级联动：复用 `CategoryCascader` 组件（`src/components/CategoryCascader.vue`，内部封装一级/二级/三级三个 `el-select`，选上级自动加载下级、清空下级）。列表展示**当前选中层级下的子分类**（选一级→列二级，选二级→列三级），用单个 `el-table` 复用。

**新增规则（关键）**：一级分类由系统预置、无新增接口；因此「新增」按钮仅在选择一级或二级时可用——选一级→新增二级，选二级→新增三级（`canAdd = addLevel >= 2`）。即便所选层级下的子分类列表为空（初次建立分类的初始状态），也能直接点「新增」按钮补建下级，无需先有数据。

```vue
<script setup lang="ts">
import { Plus } from '@element-plus/icons-vue'
import { ElMessage } from 'element-plus'
import { computed, ref, watch } from 'vue'
import { client } from '@/api/client'
import type { components } from '@/api/schema'
import CategoryCascader from '@/components/CategoryCascader.vue'

type Category2 = components['schemas']['types.Category2']
type Category3 = components['schemas']['types.Category3']

const c1Id = ref('')
const c2Id = ref('')
const c3Id = ref('')

const loading = ref(false)
const tableData = ref<(Category2 | Category3)[]>([])
const name = ref('')
const dialogVisible = ref(false)
const saving = ref(false)

// 当前要新增的层级：选了一级 → 新增二级；选了二级 → 新增三级；选了三级 → 三级为末级不再新增
// 选一级时表格列「该一级下的二级」，选二级时列「该二级下的三级」（即便为空也能直接新增）
const addLevel = computed(() => (c2Id.value ? 3 : c1Id.value ? 2 : 1))
const addLabel = computed(() => (addLevel.value === 2 ? '二级分类' : '三级分类'))
// 一级分类由系统预置，无新增接口；选了一级才能新增二级，选二级才能新增三级
const canAdd = computed(() => addLevel.value >= 2)

async function loadTable() {
  loading.value = true
  try {
    if (c2Id.value) {
      // 选了二级 → 列出该二级下的三级分类（可能为空的初始状态也能直接新增三级）
      tableData.value =
        (
          await client.GET('/api/v1/product/category3/{category2Id}', {
            params: { path: { category2Id: c2Id.value } },
          })
        ).data?.data ?? []
    } else if (c1Id.value) {
      // 选了一级 → 列出该一级下的二级分类
      tableData.value =
        (
          await client.GET('/api/v1/product/category2/{category1Id}', {
            params: { path: { category1Id: c1Id.value } },
          })
        ).data?.data ?? []
    } else {
      tableData.value = []
    }
  } finally {
    loading.value = false
  }
}

watch([c1Id, c2Id, c3Id], loadTable)

function openAdd() {
  name.value = ''
  dialogVisible.value = true
}

async function save() {
  if (!name.value.trim()) {
    ElMessage.warning('请输入名称')
    return
  }
  saving.value = true
  try {
    if (addLevel.value === 2) {
      await client.POST('/api/v1/product/category2', {
        body: { category1Id: c1Id.value, name: name.value },
      })
    } else {
      await client.POST('/api/v1/product/category3', {
        body: { category2Id: c2Id.value, name: name.value },
      })
    }
    ElMessage.success('新增成功')
    dialogVisible.value = false
    await loadTable()
  } finally {
    saving.value = false
  }
}
</script>

<template>
  <div class="category">
    <el-card>
      <CategoryCascader v-model:c1="c1Id" v-model:c2="c2Id" v-model:c3="c3Id" />

      <template v-if="c1Id">
        <el-button
          v-auth="'btn.Category.add'"
          type="primary"
          :icon="Plus"
          style="margin-top: 12px"
          :disabled="!canAdd"
          @click="openAdd"
        >
          新增{{ addLabel }}
        </el-button>

        <el-table v-loading="loading" :data="tableData" border style="margin-top: 12px">
          <el-table-column type="index" label="序号" width="80" />
          <el-table-column prop="name" label="分类名称" />
        </el-table>
      </template>
    </el-card>

    <el-dialog v-model="dialogVisible" :title="`新增${addLabel}`">
      <el-form label-width="100px">
        <el-form-item label="名称" required>
          <el-input v-model="name" placeholder="请输入分类名称" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" :loading="saving" @click="save">确定</el-button>
      </template>
    </el-dialog>
  </div>
</template>
```

> 说明：`CategoryCascader` 通过 `v-model:c1/c2/c3` 双向绑定三级 id，父组件（分类页 / SPU 页 / 平台属性页）只关心 id 值。三级分类是末级，SPU 必须挂在三级分类下（见阶段 11.2）。

## 阶段 11：平台属性 + SPU 管理

### 11.1 平台属性 `views/product/attr/index.vue`

依赖三级分类（见阶段 10 的级联），选定三级后才加载属性列表。属性值内联编辑（标签 + 输入态），提交时整组带上去。

```vue
<script setup lang="ts">
import { Delete, Edit } from '@element-plus/icons-vue'
import { onMounted, reactive, ref } from 'vue'
import { client } from '@/api/client'
import type { components } from '@/api/schema'

type Attr = components['schemas']['types.Attr']

const c1Id = ref('')
const c2Id = ref('')
const c3Id = ref('')
const list = ref<Attr[]>([])
const dialogVisible = ref(false)
const form = reactive<Partial<Attr>>({ attrName: '', attrValueList: [] })
const inputVal = ref('')

async function loadAttr() {
  if (!c1Id.value || !c2Id.value || !c3Id.value) {
    list.value = []
    return
  }
  list.value = (await client.GET(
    '/api/v1/product/attr/{category1Id}/{category2Id}/{category3Id}',
    { params: { path: {
        category1Id: c1Id.value, category2Id: c2Id.value, category3Id: c3Id.value,
    } } },
  )).data?.data ?? []
}
function openAdd() {
  Object.assign(form, { attrName: '', attrValueList: [], categoryId: c3Id.value })
  dialogVisible.value = true
}
function openEdit(row: Attr) {
  Object.assign(form, { ...row, attrValueList: [...(row.attrValueList ?? [])] })
  dialogVisible.value = true
}
function addValue() {
  const v = inputVal.value.trim()
  if (v && !(form.attrValueList ?? []).some((x) => x.valueName === v)) {
    form.attrValueList?.push({ valueName: v })
  }
  inputVal.value = ''
}
function removeValue(i: number) {
  form.attrValueList?.splice(i, 1)
}
async function save() {
  try {
    await client.POST('/api/v1/product/attr', {
      body: {
        attrId: form.attrId,
        attrName: form.attrName ?? '',
        categoryId: form.categoryId ?? '',
        attrValueList: form.attrValueList ?? [],
      },
    })
    ElMessage.success('保存成功')
    dialogVisible.value = false
    await loadAttr()
  } catch { /* 中间件已提示 */ }
}
async function remove(row: Attr) {
  try {
    await client.DELETE('/api/v1/product/attr/{attrId}', {
      params: { path: { attrId: String(row.attrId) } },
    })
    ElMessage.success('删除成功')
    await loadAttr()
  } catch { /* 中间件已提示 */ }
}

// 三级联动回调：阶段 10 同款，这里仅触发 loadAttr
async function onC3(id: string) {
  c3Id.value = String(id)
  await loadAttr()
}

onMounted(loadAttr)
</script>

<template>
  <div>
    <!-- 三级分类联动选择（复用阶段 10 的级联组件或简版下拉） -->
    <el-alert v-if="!c3Id" title="请先选择三级分类" type="info" :closable="false" style="margin-bottom: 16px" />

    <el-button type="primary" :icon="Plus" :disabled="!c3Id" @click="openAdd">添加属性</el-button>

    <el-table :data="list" border style="margin-top: 16px">
      <el-table-column type="index" label="序号" width="70" align="center" />
      <el-table-column prop="attrName" label="属性名称" />
      <el-table-column label="属性值">
        <template #default="{ row }">
          <el-tag v-for="v in row.attrValueList" :key="v.attrValueId" style="margin: 2px">{{ v.valueName }}</el-tag>
        </template>
      </el-table-column>
      <el-table-column label="操作" width="160">
        <template #default="{ row }">
          <el-button size="small" :icon="Edit" @click="openEdit(row)" />
```

### 11.2 SPU 管理 `views/product/spu/index.vue`

## 统一检查清单（实现后核对）

- [ ] 所有接口走 `client.GET/POST/PUT/DELETE`，无 axios / request.ts / code===200 判断
- [ ] 路径参数用 `params.path`，且为**字符串**（`String(id)`）
- [ ] `el-upload` 的 `:action` 为 `/api/v1/product/fileUpload`、`:headers` 带 `Authorization: Bearer` + `localStorage` token
- [ ] 主键用真实字段（`trademarkId`/`spuId`/`skuId`），不写 `row.id`
- [ ] 图标用 `@element-plus/icons-vue` 按需 import（如 `Plus`/`Edit`/`Delete`/`View`），模板用 `:icon` 绑定；`ElMessage` 不 import（按需补 style）
- [ ] 列表页复用 `useCrudTable`，不重写分页样板
- [ ] 类型全部来自 `schema.d.ts`，无手写 `type.ts`
- [ ] 价格/重量按 `priceCent`/`weightMg`（分/毫克）换算提交
