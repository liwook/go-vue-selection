## 步骤 1：准备素材

### 1.1 头像图标 — 用 Element Plus 现成方案 ✅

> 注：本项目尚未搭建「`src/icons/*.svg` + `<SvgIcon>` 本地 svg 组件」机制（阶段 1 未落地该部分），因此这里**不依赖虚构的 `welcome.svg`**，改用 Element Plus 已具备的能力：
>
> - `el-avatar`：圆形头像容器（由 `ElementPlusResolver` 自动导入，模板里直接用，不用 `import`）。

## 步骤 2：重写首页 `src/views/home/index.vue`

把原来的占位页完整替换为以下代码：

```vue
<template>
  <div class="home">
    <el-card class="home-card">
      <!-- 左侧：问候区域 -->
      <div class="home-greeting">
        <!-- 圆形头像：el-avatar（蓝底）+ User 图标 -->
        <el-avatar class="home-avatar" :size="72">
          <el-icon :size="36"><User /></el-icon>
        </el-avatar>
        <!-- 文字信息 -->
        <div class="home-text">
          <h1 class="home-greeting-text">{{ greeting }}{{ displayName }}</h1>
          <p class="home-subtitle">硅谷甄选运营平台</p>
        </div>
      </div>

      <!-- 右侧：插画 -->
      <div class="home-illustration">
        <img :src="illustrationSrc" alt="欢迎插画" />
      </div>
    </el-card>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue'
import useUserStore from '@/store/modules/user'
// 插画图片：步骤 1.2 新建的 home-illustration.svg（或改用 @/assets/hero.png）
import illustrationImg from '@/assets/home-illustration.svg'

const userStore = useUserStore()

// —— 问候语：根据当前时间段返回不同文案 ——
const greeting = computed(() => {
  const hour = new Date().getHours()
  if (hour < 12) return '上午好 '
  if (hour < 18) return '下午好 '
  return '晚上好 '
})

// —— 显示名：取用户昵称 name，Pinia 取，未登录/接口未通时兜底为 admin，避免显示 undefined ——
const displayName = computed(() => userStore.userInfo?.name ?? 'admin')

// 插画图片源（后续换图只需改这里）
const illustrationSrc = illustrationImg
</script>

<style scoped lang="scss">
.home {
  // 让整个 home 区域高度撑满父容器（layout_main 的内容区）
  height: 100%;
  display: flex;
  align-items: center;
  justify-content: center;
  background: #f0f2f5; // 浅灰底，让白色卡片悬浮居中
}

.home-card {
  width: 80%;
  max-width: 900px;
  border-radius: 12px;
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.06);
  transition:
    transform 0.25s,
    box-shadow 0.25s;

  &:hover {
    transform: translateY(-4px);
    box-shadow: 0 12px 32px rgba(0, 0, 0, 0.1);
  }

  // 卡片内部左右排列
  :deep(.el-card__body) {
    display: flex;
    align-items: center;
    justify-content: space-between;
    padding: 40px 48px;
  }
}

// 左侧问候区域
.home-greeting {
  display: flex;
  align-items: center;
  gap: 20px;
}

// 圆形头像：蓝底白图标（el-avatar 自带圆形，这里改底色）
.home-avatar {
  background: #409eff; // Element Plus 主色蓝
  color: #fff;
  flex-shrink: 0; // 防止被压缩
}

// 文字部分
.home-text {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

.home-greeting-text {
  font-size: 28px;
  font-weight: 700;
  color: #303133;
  margin: 0;
}

.home-subtitle {
  font-size: 15px;
  color: #909399;
  margin: 0;
}

// 右侧插画
.home-illustration {
  img {
    max-width: 320px;

  }
}

// 窄屏（<768px）：卡片内改为纵向堆叠、文字居中，避免溢出
```

### 代码逐块讲解

#### 模板部分（`<template>`）

```text
外层 div.home          → 撑满父容器 + flex 居中
  └─ el-card           → Element Plus 卡片组件（自动导入，不用 import）
       ├─ 左侧 .home-greeting   → 头像 + 文字
       │    ├─ .home-avatar     → el-avatar 圆形容器 + <User /> 图标
       │    └─ .home-text       → h1 问候语 + p 副标题
       └─ 右侧 .home-illustration → <img> 插画
```

- **`<el-avatar>` + `<User />`**：`el-avatar` 是 Element Plus 圆形头像容器（自动导入），`<User />` 是 `@element-plus/icons-vue` 的图标，经 EP Resolver 自动导入，模板里直接写即可，无需 `import`。蓝底白图标由 `.home-avatar` 的 `background` / `color` 控制。
- **`{{ greeting }}{{ displayName }}`**：`greeting` 是计算属性（"上午好 "），`displayName` 是另一个计算属性，从 Pinia `userStore.userInfo?.name` 取用户昵称，未登录时兜底 `'admin'`，避免显示 `undefined`。
- **`:src="illustrationSrc"`**：Vue 里动态绑图片源必须用 `:src`（不能写死字符串 `src="..."`），否则 Vite 打包后路径不对。

#### 脚本部分（`<script setup>`）

```ts
import useUserStore from '@/store/modules/user' // 取用户名
import illustrationImg from '@/assets/home-illustration.svg' // Vite 导入图片
```

- **Pinia 取用户名**：`userStore.userInfo?.name` 就是登录时后端返回的用户名（来自 `userinfoAPI` → 存入 `userInfo`）。用可选链 `?.` + 兜底 `?? 'admin'`，即使未登录/接口未通也不会显示 `undefined`。
- **Vite 图片导入**：`import xxx from '@/assets/xxx.svg'` 是 Vite 的特殊语法，导入后 `xxx` 变成打包后的**正确路径字符串**。直接写 `/src/assets/xxx.svg` 不行，因为开发环境和打包后的路径不同。

#### 样式部分（`<style scoped lang="scss">`）

- **`height: 100%` + `display: flex` + `align-items/justify-content: center`**：让卡片在内容区**垂直水平居中**。这是最常用的居中方案之一。
- **`:deep(.el-card__body)`**：`scoped` 样式默认不会穿透到子组件（`el-card` 内部的 `.el-card__body` 是 Element Plus 生成的）。用 `:deep()` 可以"穿透" scoped 边界去控制子组件内部的样式。
- **`flex-shrink: 0`**：防止头像圆圈在空间不够时被压扁。flex 默认 `shrink: 1`（允许压缩），头像要固定大小所以关掉。
- **`@media (max-width: 768px)`**：窄屏时把卡片内部改为纵向堆叠、文字居中，避免插画把卡片撑爆。
- **SCSS 全局变量（如已配置）**：若 `vite.config.ts` 用 `additionalData` 全局注入了 `variables.scss`（见文档 02），其中的变量（如 `$sidebar-width`）可直接在 `<style lang="scss">` 里使用。本页面暂未用到，这里保留 `.home` 内的局部样式即可。

## 步骤 4：学习要点总结

做完这个页面，你实际上练习了以下前端核心知识点：

| 知识点                 | 在哪里用到                                          | 为什么重要                                        |
| ---------------------- | --------------------------------------------------- | ------------------------------------------------- |
| **Pinia 状态读取**     | `userStore.userInfo?.name`                          | 跨组件共享数据（用户信息在 store 里，页面直接读） |
| **computed 计算属性**  | `greeting` / `displayName`（根据时间/状态算派生值） | 派生数据，依赖不变就不重新算，性能好              |
| **可选链 + 兜底**      | `userInfo?.name ?? 'admin'`                         | 防止未登录时渲染出 `undefined`，提升健壮性        |
| **Element Plus 图标**  | `<el-avatar>` + `<User />`                        | 用 EP 现成组件/图标，无需自建 svg 机制，零新增资源 |
| **Flex 居中布局**      | `.home` 的 `display:flex` + center                  | 最实用的 CSS 居中方案                             |
| **`:deep()` 样式穿透** | 改 `el-card__body` 布局                             | scoped 样式下修改第三方组件内部样式的标准做法     |
| **Vite 图片导入**      | `import img from '@/assets/xxx.svg'`                | 开发/打包路径统一处理，Vite 特有能力              |
| **响应式图片**         | `max-width/max-height + object-fit:contain`         | 图片不变形、不溢出的通用写法                      |
| **媒体查询响应式**     | `@media (max-width: 768px)`                         | 窄屏下重排布局，保证移动端可读                    |
| **`flex-shrink: 0`**   | 头像圆圈防压缩                                      | Flex 布局坑点：小元素默认会被挤压                 |

### 常见报错排查

| 报错                                                    | 原因                              | 解决                                                                              |
| ------------------------------------------------------- | --------------------------------- | --------------------------------------------------------------------------------- |
| `Cannot find module '@/assets/home-illustration.svg'`   | 图片文件不存在 / 路径错           | 按步骤 1.2 新建该文件，或改用 `@/assets/hero.png`                                 |
| `Property 'name' does not exist on type 'Partial<...>'` | TS 不知道 userInfo 有 name        | 用可选链：`userStore.userInfo?.name ?? 'admin'`（本指南代码已处理）               |
| `[Vue warn]: Failed to resolve component: User`         | EP 图标未自动导入                 | 确认 `vite.config.ts` 的 `ElementPlusResolver` 已开 `importStyle` 且含 icons（见文档 02），`<User />` 由 EP Resolver 自动导入 |
| 头像没颜色 / 图标不显示                                 | `.home-avatar` 的 color/background 没生效 | 确认 `.home-avatar` 设了 `background: #409eff` 和 `color: #fff`              |
| `vue-tsc` 报 unused import                              | import 了但没用上                 | 删掉多余的 import（本项目开了 `noUnusedLocals`）                                  |
