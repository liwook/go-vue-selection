# 阶段 4 · 首页问候页实现指南

> 目标：在 `views/home/index.vue` 做一个首页问候卡片——显示「时间问候 + 用户名 + 头像」，并带简单的卡片样式。
---

## 1. 当前状态

- `src/views/home/index.vue` 只有一行占位 `<div>【占位】首页 页面</div>`，需替换。
- `useUserStore` 已提供响应式的 `name`、`avatar`，可直接在组件里读。
- 问候语由前端按当前小时计算，无需后端参与。

---

## 2. 实现 `views/home/index.vue`

### 2.1 逻辑要点

- **问候语**：按 `new Date().getHours()` 分段（早/上/下/晚），配合用户名拼接。分段规则与阶段 5 顶栏下拉 / 进入通知保持一致（见 [`08`](./08.阶段5·Layout顶栏实现指南.md)），便于全局统一。
- **用户名**：直接读 `userStore.name`（来自登录后 `getUserInfo` 拉取的 `data.name`）。
- **头像**：后端 `avatar` 为空时用默认头像兜底（`import.meta.env.BASE_URL + 'chopper.jpeg'`，该文件已置于 `public/`）。
- **store 取值**：Setup Store 返回的是 `ref`，模板里直接写 `userStore.name` 即可（自动解包），脚本里用 `userStore.name` 也是响应式的。

### 2.2 完整代码

```vue
<template>
  <el-card class="home-card" shadow="hover">
    <div class="greeting">
      <el-avatar :size="64" :src="avatarUrl" />
      <div class="text">
        <h2>{{ greeting }}，{{ userStore.name || '游客' }}</h2>
        <p>欢迎使用选课管理系统</p>
      </div>
    </div>
  </el-card>
</template>

<script setup lang="ts">
import { computed } from 'vue'
import { storeToRefs } from 'pinia'
import { useUserStore } from '@/store/modules/user'

const userStore = useUserStore()
// 用 storeToRefs 保持响应式（模板里直接用 userStore.name 也行，这里演示规范写法）
const { name, avatar } = storeToRefs(userStore)

// 默认头像兜底（public/chopper.jpeg）
const defaultAvatar = `${import.meta.env.BASE_URL}chopper.jpeg`
const avatarUrl = computed(() => avatar.value || defaultAvatar)

// 按当前小时生成问候语
const greeting = computed(() => {
  const h = new Date().getHours()
  if (h < 6) return '凌晨好'
  if (h < 12) return '早上好'
  if (h < 14) return '中午好'
  if (h < 18) return '下午好'
  return '晚上好'
})
</script>

<style scoped lang="scss">
.home-card {
  max-width: 560px;
  margin: 24px auto;
}
.greeting {
  display: flex;
  align-items: center;
  gap: 16px;
}
.text h2 {
  margin: 0 0 4px;
}
.text p {
  margin: 0;
  color: var(--el-text-color-secondary);
}
</style>
```

### 2.3 关键说明

- **`storeToRefs` vs 直接读**：模板里 `userStore.name` 会自动解包，可不用 `storeToRefs`；但凡要在 `computed`/函数里引用 state，推荐 `storeToRefs` 以保持响应式引用（避免解构丢失响应式）。
- **头像兜底**：`avatar` 可能为空串，用 `computed` 给默认值，避免 `el-avatar` 显示破图。
- **样式**：用 `scoped` + Element Plus CSS 变量（`--el-text-color-secondary`），`max-width` 居中，足够清爽，无需引入额外 UI 库。
- **无需 try/catch**：本页不调接口，`userStore` 的数据在阶段 3 登录时已填充。

## 3. 验证

1. `pnpm dev` 启动，登录后跳转到 `/home`。
2. 应看到卡片：左侧头像、右侧「<问候>，<用户名>」+ 副标题。
3. 改系统时间（或临时改 `getHours()` 阈值）核对问候语分段正确。
4. 若后端 `avatar` 为空，确认显示 `public/avatar.png` 默认头像。

---

## 4. 常见问题

- **用户名显示空/「游客」**：确认阶段 3 登录流程已调用 `getUserInfo` 并把 `data.name` 写进 `userStore.name`；可在浏览器 DevTools 看 `localStorage.token` 是否存在。
- **头像破图**：检查 `public/chopper.jpeg` 是否存在；`import.meta.env.BASE_URL` 默认 `/`，最终路径为 `/chopper.jpeg`。
- **`storeToRefs` 解构后仍不更新**：确保解构的是 `storeToRefs(userStore)` 的返回值，而不是直接解构 `userStore`（后者会丢失响应式）。
