## 1. 前置准备：依赖 + 中国地图 GeoJSON {#s1}

### 1.1 安装 echarts {#s1-1}

```bash
pnpm add echarts@^5
```

`echarts`：主图表库，本项目锁定 `^5`（按需导入 API 在 5.x 一致）。**无需安装 `echarts-liquidfill`**——水球图已改为自绘 `LiquidBall.vue`，以便 `echarts.ts` 走 `echarts/core` 按需引入，详见 [2.1 节](#s2-1)。

---

### 1.2 准备中国地图 GeoJSON {#s1-2}

ECharts 5 不再内置地图，需手动注册 GeoJSON。**推荐就近 `import`**（构建期即可校验路径、且随 `screen` 路由切到独立 chunk，不污染首屏）：把 `china.json` 放 `src/views/screen/china.json`，在 `screen/index.vue` **模块顶层** `import` 后立即 `echarts.registerMap('china', chinaJson)`（必须顶层，原因见 [坑 2](#spitfall)）。

文件已随仓库维护，无需下载；若误删，构建会直接报路径缺失，可按源地址 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json` 重新放置。

## 2. 封装通用组件 `src/components/EChart.vue`【新增】 {#s2}

把「初始化、响应式、销毁」收敛到一个组件里，避免每个图表都重复写 `echarts.init`。

```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted, watch } from 'vue'
// 按需导入：只打包用到的图表类型与组件，显著减小最终 chunk 体积
import * as echarts from 'echarts/core'
import { BarChart, PieChart, MapChart, LineChart } from 'echarts/charts'
import {
  GridComponent,
  TooltipComponent,
  LegendComponent,
  VisualMapComponent,
} from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
// 类型仅用于编译期校验，纯类型导入会被 tree-shaking 完全移除，不影响运行时体积
import type { EChartsOption, ECharts } from 'echarts'

// 注册本组件实际用到的模块（数据大屏用到柱状/饼/地图/折线 + 对应组件）
echarts.use([
  BarChart,
  PieChart,
  MapChart,
  LineChart,
  GridComponent,
  TooltipComponent,
  LegendComponent,
  VisualMapComponent,
  CanvasRenderer,
])

interface Props {
  option: EChartsOption | Record<string, unknown>
  theme?: string
}

const props = withDefaults(defineProps<Props>(), {
  theme: 'dark',
})

const chartRef = ref<HTMLDivElement>()
let chartInstance: ECharts | null = null

// 初始化
const initChart = () => {
  if (!chartRef.value) return
  chartInstance = echarts.init(chartRef.value, props.theme)
  chartInstance.setOption(props.option)
}

// option 变化时重绘（true 表示不合并，避免旧数据残留）
const updateChart = () => {
  chartInstance?.setOption(props.option, true)
}

// 容器尺寸变化时自适应（用 ResizeObserver 观察容器自身，而非 window.resize）
let observer: ResizeObserver | null = null
const observeResize = () => {
  if (!chartRef.value) return
  observer = new ResizeObserver(() => chartInstance?.resize())
  observer.observe(chartRef.value)
}

onMounted(() => {
  initChart()
  observeResize()
})

onUnmounted(() => {
  observer?.disconnect()
  if (chartInstance) {
    chartInstance.dispose()
  }
})

watch(() => props.option, updateChart, { deep: true })
</script>

<template>
  <div ref="chartRef" class="echart-container" />
</template>

<style scoped>
.echart-container {
  width: 100%;
  height: 100%;
}
</style>
```

**设计要点**：

- **按需导入**：`import * as echarts from 'echarts/core'` + `echarts.use([...])` 只引入用到的图表与组件，把近 1MB 全量包压到约 200KB；类型 `EChartsOption` / `ECharts` 用纯类型导入（编译期移除）。
- **`theme="dark"`**：内置暗黑主题，省去大量颜色配置。
- **`setOption(option, true)`**：第二参数 `true` 表示「不合并」，切换数据时旧 series 不残留。
- **`ResizeObserver` 优于 `window.resize`**：直接观察图表容器元素自身尺寸变化，而非监听 `window` 的 `resize`。好处是**列宽因 flex 重排、侧边栏收起/展开等引起的容器尺寸变化**也能触发 `chart.resize()`，而 `window.resize` 只在窗口本身变化时触发，列宽变化常被漏掉；组件卸载时 `observer.disconnect()` 即可。

> 其余细节（类型放宽为 `EChartsOption | Record<string, unknown>`、`dispose()` 判空销毁、`ResizeObserver` 监听）见 [6. 避坑与注意项](#spitfall)。

## 2.1 自绘水球组件 `src/components/LiquidBall.vue`【新增】 {#s2-1}

水球图不再依赖 `echarts-liquidfill`，改用自绘 SVG + CSS 波浪：水位由 `transform: translateY(...)` 控制，两层 `<path>` 波浪通过 `@keyframes liquid-wave` 水平往返平移形成流动观感，均走 GPU 合成，不占主线程；`resize` 由父容器尺寸决定（组件本身自适应 `size` prop），无需 ECharts 实例。

```vue
<template>
  <div class="liquid-ball" :style="{ width: size + 'px', height: size + 'px' }">
    <svg viewBox="0 0 100 100" class="liquid-ball__svg">
      <defs>
        <!-- 圆形裁剪，把波浪裁成球内区域 -->
        <clipPath id="liquid-clip">
          <circle cx="50" cy="50" r="48" />
        </clipPath>
        <linearGradient id="liquid-fill" x1="0" y1="0" x2="0" y2="1">
          <stop offset="0%" :stop-color="color" stop-opacity="0.9" />
          <stop offset="100%" :stop-color="color" stop-opacity="0.5" />
        </linearGradient>
      </defs>

      <!-- 球底（未填充部分） -->
      <circle cx="50" cy="50" r="48" class="liquid-ball__bg" />

      <!-- 水位 + 两层波浪，用 clip 裁出圆形 -->
      <g clip-path="url(#liquid-clip)">
        <g :style="{ transform: `translateY(${(1 - clamped) * 100}%)` }" class="liquid-ball__wave-group">
          <path
            class="liquid-ball__wave liquid-ball__wave--back" :fill="color" fill-opacity="0.5"
            d="M0 50 Q 12.5 35 25 50 T 50 50 T 75 50 T 100 50 T 125 50 T 150 50 V100 H0 Z"
          />
          <path
            class="liquid-ball__wave liquid-ball__wave--front" :fill="color"
            d="M0 50 Q 12.5 35 25 50 T 50 50 T 75 50 T 100 50 T 125 50 T 150 50 V100 H0 Z"
          />
        </g>
      </g>

      <!-- 球边框 -->
      <circle cx="50" cy="50" r="48" class="liquid-ball__border" />
    </svg>

    <!-- 居中百分比 -->
    <span class="liquid-ball__label" :style="{ color: textColor }">
      {{ percent }}%
    </span>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue'

const props = withDefaults(
  defineProps<{
    /** 水位比例，0~1 */
    value: number
    /** 直径像素 */
    size?: number
    /** 主题色 */
    color?: string
    /** 文字颜色 */
    textColor?: string
  }>(),
  { size: 140, color: '#4fc3f7', textColor: '#ffffff' },
)

const clamped = computed(() => Math.min(1, Math.max(0, props.value)))
const percent = computed(() => Math.round(clamped.value * 100))
</script>

<style scoped lang="scss">
.liquid-ball {
  position: relative;
  display: inline-block;
}

.liquid-ball__svg {
  width: 100%;
  height: 100%;
  display: block;
}

.liquid-ball__bg {
  fill: rgba(79, 195, 247, 0.08);
}

.liquid-ball__border {
  fill: none;
  stroke: rgba(79, 195, 247, 0.6);
  stroke-width: 2;
}

// 水位整体上下平移由 transform 控制（GPU 合成，不占主线程）
.liquid-ball__wave-group {
  transition: transform 0.6s ease-out;
  will-change: transform;
}

// 两层波浪做水平往返平移，形成流动观感
.liquid-ball__wave {
  animation: liquid-wave 3.5s linear infinite;
}

.liquid-ball__wave--back {
  animation-duration: 4.5s;
  animation-direction: reverse;
  opacity: 0.6;
}

@keyframes liquid-wave {
  from {
    transform: translateX(0);
  }
  to {
    // 一个完整波长为 50（viewBox 单位），平移 -50 即可无缝循环
    transform: translateX(-50px);
  }
}

.liquid-ball__label {
  position: absolute;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 26px;
  font-weight: 700;
  text-shadow: 0 0 8px rgba(0, 0, 0, 0.4);
}

// 尊重无障碍：减少动态偏好时停掉动画
@media (prefers-reduced-motion: reduce) {
  .liquid-ball__wave {
    animation: none;
  }
}
</style>
```

**Props 说明**：

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number` | —（必填） | 水位填充比例，`0~1`，内部 `clamp` 到 `[0,1]` 并显示百分比 |
| `size` | `number` | `140` | 水球直径（像素），正方形 |
| `color` | `string` | `'#4fc3f7'` | 波浪/边框主题色 |
| `textColor` | `string` | `'#ffffff'` | 居中百分比文字颜色 |

> 使用方式见第 4 节 `screen/index.vue`：`<LiquidBall :value="data.realTimeStats.trend" />`，`trend` 即 `realTimeStats.trend`（0~1 的填充比例）。

## 3. 数据层 `useScreenData` + 本地 mock `mockData.ts`【新增】 {#s3}

数据层分两层：`mockData.ts` 提供静态 mock 数据；`useScreenData.ts` 是页面统一取数入口——当前内部返回 mock，将来可无缝替换为后端轮询（`setInterval` + `fetch`）或 WebSocket 推送，页面组件无需改动。

```ts
// src/views/screen/useScreenData.ts
import { ref, onUnmounted } from 'vue'
import * as mock from './mockData'

export function useScreenData() {
  // 当前：直接返回 mock
  const data = ref(mock)

  // 预留：后端接入位（轮询 / WebSocket）
  // function startPolling() {
  //   setInterval(() => fetch('/api/screen').then(r => r.json()).then(d => data.value = d), 5000)
  // }
  // function connectWS() {
  //   const ws = new WebSocket('/ws/screen')
  //   ws.onmessage = e => data.value = JSON.parse(e.data)
  // }

  onUnmounted(() => { /* 清理定时器 / 关闭 ws */ })
  return { data }
}
```

## 4. 重写大屏页面 `src/views/screen/index.vue`【重写】 {#s4}

整体思路：

- 页面铺满视口：`width: 100vw; height: 100vh; overflow: hidden;`
- 背景用深色径向渐变 + 星空/网格装饰（按截图风格）。
- 顶部固定高度，主体用 CSS Grid 分三列：左 28% / 中 44% / 右 28%。
- 每个图表卡片统一标题样式：小标题 + 装饰线 + 英文副标题。
- 中国地图在**模块顶层**用 `import` 进来的 `chinaJson` 注册（`echarts.registerMap('china', chinaJson)`），确保子组件渲染前地图已就绪（详见 [6. 避坑与注意项 · 坑 2](#spitfall)）。

```vue
import { useRouter } from 'vue-router'
// 统一按需入口（echarts/core + echarts.use([...])），已移除 echarts-liquidfill，
// 水球图改用自绘组件 LiquidBall.vue，全页可放心走按需导入，不必再为 liquidfill 保留全量 echarts。
import echarts, { type EChartsOption, type TopLevelFormatterParams } from '@/components/echarts'
import type { CallbackDataParams } from 'echarts/types/dist/shared'
import EChart from '@/components/EChart.vue'
import LiquidBall from '@/components/LiquidBall.vue'
import chinaJson from './china.json'

// ⚠️ 注册必须放模块顶层：保证子组件 EChart 的 onMounted 调 setOption 前地图已就绪

onMounted(() => {
```

## 6. 避坑与注意项 {#spitfall}

| # | 坑 | 要点 |
| --- | --- | --- |
| 1 | 水球图用自绘 `LiquidBall.vue` | 不要用 `echarts-liquidfill`（会锁死全量 echarts，gzip ~600KB）；`<LiquidBall :value="trend" />`，`value` 为 0~1 比例 |
| 2 | 地图空白 `Map china not exists` | `registerMap('china', chinaJson)` 必须放 `screen/index.vue` **模块顶层**（`import` 之后），不要在 `onMounted` 里；省份 `name` 须与 `peakWarning` 一致（如「北京市」） |
| 3 | 图表高度 0 | ECharts 需明确高度，靠 `panel-body { flex:1; min-height:0 }` + `EChart { width:100%; height:100% }` 解决 |
| 4 | 被 Layout 包裹 | `screen` 路由须为 `routes.ts` **顶层路由**，不挂 Layout，否则出现侧边菜单 |
| 5 | 内存泄漏 | `EChart.vue` 的 `onUnmounted` 里 `dispose()` + `observer.disconnect()`，否则反复进出堆积实例 |
| 6 | `vue-tsc` 类型报错 | ① option 用 `computed<EChartsOption>` 标注避免字面量被推宽；② `china.json` 勿写 `as any`；③ 回调参数用 `CallbackDataParams` / `TopLevelFormatterParams`（从 `echarts/types/dist/shared` 引入），别用 `any` |

## 7. 学习要点总结 {#slearn}

| 要点 | 关键代码 / 文件 | 说明 |
| --- | --- | --- |
| ECharts 封装 | `EChart.vue` | init / setOption / resize / dispose 收敛，页面只传 option |
| 暗黑主题 | `echarts.init(dom, 'dark')` | 内置主题，少写颜色 |
| 地图注册 | `registerMap('china', geoJson)` | ECharts 5 需手动注册 GeoJSON（模块顶层） |
| 按需导入 | `echarts.ts`：`echarts/core` + `echarts.use([...])` | 只引入用到的图表，体积 ~1MB → ~200KB |
| 水球图 | `<LiquidBall :value="trend" />` | 自绘 SVG，不依赖 liquidfill |
| 全屏独立页 | `routes.ts` 顶层路由 | 不挂 Layout |
| 实时时间 | `setInterval` | unmounted 清理定时器 |
| 响应式 | `ResizeObserver` + `resize()` | 观察容器自身，比 `window.resize` 稳 |
