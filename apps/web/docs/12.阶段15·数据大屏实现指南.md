## 1. 前置准备：依赖 + 中国地图 GeoJSON {#s1}

### 1.1 安装 echarts / echarts-liquidfill {#s1-1}

```bash
pnpm add echarts@^5 echarts-liquidfill@^3
```

> - `echarts`：主图表库，本项目锁定 **`^5`**。原因：`echarts-liquidfill@3`（水球图扩展）官方对应 **echarts 5**；若装 echarts 6，liquidfill 大概率无法渲染（6.x 与 liquidfill 3 兼容性未验证）。按需导入 API 在 5.x 完全一致。
> - `echarts-liquidfill`：水球图扩展，用于「实时游客统计」里的波浪球效果，版本须与 echarts 5 匹配（v3）。

安装后 `package.json` 的 `dependencies` 会出现：

```json
"echarts": "^5.5.0",
"echarts-liquidfill": "^3.1.0"
```

> 版本号以 `pnpm add` 后实际写入为准，上述仅为示例。

---

### 1.2 准备中国地图 GeoJSON {#s1-2}

ECharts 5 不再内置地图，需要手动注册 GeoJSON。**推荐就近 `import` 方式**：把 `china.json` 放在 `src/views/screen/china.json`，由 `screen/index.vue` 直接 `import` 进来后 `echarts.registerMap('china', chinaJson)` 注册。

这样做的好处是：**路径错误会在构建期直接报错**，而不是运行时地图静默空白；且 `china.json` 跟随 `screen` 路由的异步组件被切到独立 chunk，不污染首屏主包——更利于生产环境。

**步骤**：

1. 下载标准中国地图 GeoJSON（例如阿里云 DataV：`https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`），保存为 `src/views/screen/china.json`。
2. 在 `screen/index.vue` 顶部 `import chinaJson from './china.json'`，并在 `onMounted` 里 `echarts.registerMap('china', chinaJson)` 注册（见第 4 节示例）。

> ⚠️ **这个文件必须下载**：仓库里不含 `china.json`，没放它地图区会直接空白。开发阶段拿不到可先注释掉 `import` 与注册行（地图空白但不报错），拿到文件后恢复即生效。
>
> 💡 **为什么不放在 `public/`？** `public/map/china.json` + 运行时 `fetch` 虽零配置，但文件缺失/路径拼错构建期不报错，只有线上地图白屏才发现；且大文件游离在模块依赖图外易被误提交。生产环境优先选 `import` 方案。

## 2. 封装通用组件 `src/components/EChart.vue`【新增】 {#s2}

把「初始化、响应式、销毁」收敛到一个组件里，避免每个图表都重复写 `echarts.init`。

```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted, watch } from 'vue'
// 按需导入：只打包用到的图表类型与组件，显著减小最终 chunk 体积
import * as echarts from 'echarts/core'
import { BarChart, PieChart, MapChart, LineChart } from 'echarts/charts'
import {
  GridComponent,
  TooltipComponent,
  LegendComponent,
  VisualMapComponent,
} from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
// 类型仅用于编译期校验，纯类型导入会被 tree-shaking 完全移除，不影响运行时体积
import type { EChartsOption, ECharts } from 'echarts'

// 注册本组件实际用到的模块（数据大屏用到柱状/饼/地图/折线 + 对应组件）
echarts.use([
  BarChart,
  PieChart,
  MapChart,
  LineChart,
  GridComponent,
  TooltipComponent,
  LegendComponent,
  VisualMapComponent,
  CanvasRenderer,
])

interface Props {
  option: EChartsOption | Record<string, unknown>
  theme?: string
}

const props = withDefaults(defineProps<Props>(), {
  theme: 'dark',
})

const chartRef = ref<HTMLDivElement>()
let chartInstance: ECharts | null = null

// 初始化
const initChart = () => {
  if (!chartRef.value) return
  chartInstance = echarts.init(chartRef.value, props.theme)
  chartInstance.setOption(props.option)
}

// option 变化时重绘（true 表示不合并，避免旧数据残留）
const updateChart = () => {
  chartInstance?.setOption(props.option, true)
}

// 窗口缩放时自适应
const handleResize = () => {
  chartInstance?.resize()
}

onMounted(() => {
  initChart()
  window.addEventListener('resize', handleResize)
})

onUnmounted(() => {
  window.removeEventListener('resize', handleResize)
  if (chartInstance) {
    chartInstance.dispose()
  }
})

watch(() => props.option, updateChart, { deep: true })
</script>

<template>
  <div ref="chartRef" class="echart-container" />
</template>

<style scoped>
.echart-container {
  width: 100%;
  height: 100%;
}
</style>
```

**设计要点**：

- **按需导入**：`import * as echarts from 'echarts/core'` + `echarts.use([...])` 只引入用到的图表与组件，把近 1MB 全量包压到约 200KB；类型 `EChartsOption` / `ECharts` 用纯类型导入（编译期移除）。
- **`theme="dark"`**：内置暗黑主题，省去大量颜色配置。
- **`setOption(option, true)`**：第二参数 `true` 表示「不合并」，切换数据时旧 series 不残留。

> 其余细节（类型放宽为 `EChartsOption | Record<string, unknown>`、`dispose()` 判空销毁、全局 `resize` 监听）见 [6. 避坑与注意项](#spitfall)。

## 4. 重写大屏页面 `src/views/screen/index.vue`【重写】 {#s4}

整体思路：

- 页面铺满视口：`width: 100vw; height: 100vh; overflow: hidden;`
- 背景用深色径向渐变 + 星空/网格装饰（按截图风格）。
- 顶部固定高度，主体用 CSS Grid 分三列：左 28% / 中 44% / 右 28%。
- 每个图表卡片统一标题样式：小标题 + 装饰线 + 英文副标题。
- 中国地图在 `onMounted` 里用 `import` 进来的 `chinaJson` 注册（`echarts.registerMap('china', chinaJson)`）。

下面是完整示例代码（可直接作为实现目标）：

```vue
<script setup lang="ts">
import { ref, computed, onMounted, onUnmounted } from 'vue'
import { useRouter } from 'vue-router'
// 注意：本页用到「水球图」echarts-liquidfill，该扩展内部依赖全量 echarts
// （import * as echarts from 'echarts/lib/echarts'），无法与 echarts/core 按需实例配对，
// 因此本页必须保留全量导入 + 副作用导入 liquidfill。
import * as echarts from 'echarts'
import 'echarts-liquidfill'
import type { CallbackDataParams } from 'echarts'
import EChart from '@/components/EChart.vue'
import {
  realTimeStats,
  genderRatio,
  ageRatio,
  hotScenicSpots,
  yearlyComparison,
  monthlyTrend,
  channelStats,
  peakWarning,
} from './mockData'

const router = useRouter()

// 顶部实时时间
const currentTime = ref('')
let timer: number | null = null
const updateTime = () => {
  const now = new Date()
  currentTime.value = now.toLocaleString('zh-CN', {
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
    hour: '2-digit',
    minute: '2-digit',
    second: '2-digit',
  })
}

// 地图 GeoJSON（就近 import，构建期即可校验路径）
import chinaJson from './china.json'

onMounted(() => {
  updateTime()
  timer = window.setInterval(updateTime, 1000)
  // china.json 已在编译期打包进 /screen 路由 chunk，直接注册即可
  echarts.registerMap('china', chinaJson)
})

onUnmounted(() => {
  if (timer) clearInterval(timer)
})

// ---------- 各图表 option ----------

// 1. 实时游客统计 - 水球图
const liquidOption = computed(() => ({
  series: [
    {
      type: 'liquidFill',
      data: [realTimeStats.trend],
      radius: '80%',
      center: ['50%', '55%'],
      color: ['#00d4ff'],
      backgroundStyle: { color: 'rgba(0, 212, 255, 0.1)' },
      outline: {
        show: true,
        borderDistance: 4,
        itemStyle: { borderColor: '#00d4ff', borderWidth: 2 },
      },
      label: { show: false },
    },
  ],
}))

// 2. 男女比例
const genderOption = computed(() => ({
  grid: { top: 30, bottom: 20, left: 40, right: 20 },

  yAxis: {
    type: 'category',
    data: ['女士', '男士'],
    axisLine: { show: false },
    axisTick: { show: false },
    axisLabel: { color: '#fff' },
  },
  series: [
    {
      type: 'bar',
      data: [genderRatio.female, genderRatio.male],
      barWidth: 16,
      itemStyle: {
        borderRadius: 8,
        color: (params: CallbackDataParams) =>
          params.dataIndex === 0 ? '#ff6b81' : '#00d4ff',
      },
      label: { show: true, position: 'right', formatter: '{c}%', color: '#fff' },
    },
  ],
}))

// 3. 年龄比例
const ageOption = computed(() => ({
  color: ['#00d4ff', '#0e6eff', '#ff9f43', '#ff6b81', '#a55eea'],
  tooltip: { trigger: 'item' },
  legend: { top: '5%', left: 'center', textStyle: { color: '#fff' } },

    {
      type: 'pie',
      radius: ['40%', '70%'],
      avoidLabelOverlap: false,
      itemStyle: { borderRadius: 6, borderColor: '#0b122e', borderWidth: 2 },

    },
  ],
}))

const mapOption = computed(() => ({
```

## 6. 避坑与注意项 {#spitfall}

### 坑 1：水球图不显示

`echarts-liquidfill` 必须在 ECharts 初始化之前被导入。最简单做法是在 `screen/index.vue` 的 `<script>` 顶部写：

```ts
import 'echarts-liquidfill'
```

也可以在 `EChart.vue` 里全局引入，这样任何页面用水球图都无需再导入。

> **重要限制**：echarts-liquidfill v3 内部依赖**全量 echarts 实例**进行扩展注册，它**无法**挂到 `echarts/core` 的按需实例（`echarts.use(...)`）上。因此只要页面用到水球图，`screen/index.vue` 就必须使用**全量导入** `import * as echarts from 'echarts'`（不能改成按需方式，否则水球图不会注册、无法显示）。通用组件 `EChart.vue` 不渲染水球图，可放心使用按需导入以减小体积。
>
> **版本兼容性提示**：本指南示例用 `echarts@^6` + `echarts-liquidfill@^3.1.0`，而 liquidfill v3 主要面向 echarts 5 适配。若实际运行水球图异常，优先确认 liquidfill 是否与 echarts 6 兼容（必要时降到 `echarts@^5`），或改用官方 ECharts 6 推荐的水球实现。

### 坑 2：中国地图报 `Map china not exists`

ECharts 5 没有内置地图，必须 `echarts.registerMap('china', geoJson)`。注意：

- `registerMap` 要在 `init` 之前执行；
- `geoJson` 结构要对（标准 GeoJSON FeatureCollection）；
- 城市 `name` 字段要与 `mockData.ts` 里的 `peakWarning` 名称一致。

### 坑 3：图表在 `flex/grid` 容器里高度为 0

ECharts 需要容器有明确高度。本项目通过 `panel-body { flex: 1; min-height: 0; }` + `EChart.vue { width: 100%; height: 100%; }` 解决。如果某图表空白，先检查父容器是否给了高度。

### 坑 4：`screen/index.vue` 被 Layout 包裹

`screen` 路由在 `routes.ts` 里是**顶层路由**（不挂在 `/` 的 `Layout` 下面），所以直接全屏。如果以后误把它改成 `Layout` 的子路由，就会出现左侧菜单 + 顶部栏，破坏大屏效果。

### 坑 5：内存泄漏

切出大屏页时务必在 `EChart.vue` 的 `onUnmounted` 里 `dispose()`，并移除 `resize` 事件监听。否则反复进出 `/screen` 会堆积多个 ECharts 实例。

### 坑 6：类型检查（liquidFill / 字面量 / 禁止 `any`）

`vue-tsc -b` 是构建时的类型检查主力（ESLint 仅 lint `.vue` 模板，不查 TS 的 `any`）。大屏里容易踩三类类型坑：

1. **`liquidFill` 不在标准类型中**：`echarts-liquidfill` 的 `type: 'liquidFill'` 不在 `EChartsOption` 联合类型里；`computed(() => ({...}))` 手写的普通对象，`tooltip.trigger: 'item'`、`series.type: 'map'` 等会被 TS 推成宽泛 `string`，报：`Type 'string' is not assignable to type '"item" | "axis" | "none"'` / `Type '{ type: "liquidFill"; ... }' is not assignable to type 'SeriesOption'`。
   **统一解法**：`EChart.vue` 的 prop 放宽为 `option: EChartsOption | Record<string, unknown>`，所有图表 option（含 liquidFill、普通字面量）都能直接传入，无需逐处 `as EChartsOption`。代价是 `option` 失去强类型校验，对手写配置是可接受取舍（运行时不受影响）。

2. **地图注册别加 `as any`**：`import chinaJson from './china.json'` 引入的对象已是 `any`（GeoJSON 结构 TS 不强制），不要写成 `as any`，否则若开 Biome `noExplicitAny` 或文件级 ESLint 会报错：

   ```ts
   import chinaJson from './china.json'
   echarts.registerMap('china', chinaJson) // 不要写 as any
   ```

3. **series 回调参数别用 `(params: any)`**：`itemStyle.color`、`label.formatter` 等回调改用官方类型：

   ```ts
   import type { CallbackDataParams } from 'echarts'
   color: (params: CallbackDataParams) =>
     params.dataIndex === 0 ? '#ff6b81' : '#00d4ff',
   ```

   `CallbackDataParams` 自带 `dataIndex`、`name`、`value`。

## 7. 学习要点总结 {#slearn}

| 要点                         | 关键代码 / 文件                                        | 说明                                                                                 |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| **ECharts 在 Vue3 中的封装** | `src/components/EChart.vue`                            | 将 init、resize、dispose、option 监听收敛，页面只需传 option                         |
| **暗黑主题**                 | `echarts.init(dom, 'dark')`                            | 内置 dark 主题，减少手写颜色配置                                                     |
| **地图注册**                 | `echarts.registerMap('china', geoJson)`                | ECharts 5 需手动注册 GeoJSON                                                         |
| **按需导入（推荐）**         | `EChart.vue`：`echarts/core` + `echarts.use([...])`    | 通用组件只引入用到的图表/组件，体积从 ~1MB 降到 ~200KB                               |
| **水球图扩展**               | `import 'echarts-liquidfill'`                          | 扩展包导入后自动挂载到**全量 echarts**；用到它的 `screen` 页必须用全量导入，不能按需 |
| **全屏独立页**               | `routes.ts` 顶层路由                                   | 不挂 Layout，实现沉浸式大屏                                                          |
| **实时时间**                 | `setInterval` 更新 ref                                 | 大屏常见元素，记得在 unmounted 清理定时器                                            |
| **响应式图表**               | `window.addEventListener('resize')` + `chart.resize()` | 保证全屏/窗口缩放时图表不变形                                                        |
